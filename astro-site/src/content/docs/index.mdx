## From sampled signals to measurements

Raw sensor samples rarely answer a question on their own. With ECG, for example, you can clean a waveform, locate R-peaks, derive RR intervals, and calculate heart rate variability. physioKIT exposes those steps as separate Python functions, so you can inspect the intermediate signals and use the measurements you need. The guides below cover pulse, respiration, and motion workflows too.

New to the library? The [quickstart](/physiokit/tutorial/quickstart/) runs that ECG workflow with synthetic data, so no external dataset is needed. Then choose a signal guide for code examples and saved visualizations, or use the [Python API](/physiokit/api/) to check function parameters and return values.

## Bring your own signal

Once you have tried a synthetic example, replace its generated samples with your own recording and set the correct sampling rate. Use the [signals overview](/physiokit/reference/) to find a matching workflow, then consult the [Python API](/physiokit/api/) for the inputs and outputs of each function. The interactive plots show saved example waveforms, not measurements from a live device.
