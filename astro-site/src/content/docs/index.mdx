## What is physioKIT?

physioKIT helps developers explore physiological data collected by wearables and other sensors. It provides Python routines for generating synthetic signals, filtering and cleaning recordings, finding events such as peaks, and calculating derived measures. The examples show how these pieces fit together; the [Python API](/physiokit/api/) documents each callable in detail.

The toolkit focuses on signal processing. It does not require a model-training workflow to get started. Install the package, try an example with synthetic data, then bring your own recordings when you are ready.

## Start with an example

The [quickstart](/physiokit/tutorial/quickstart/) installs physioKIT and walks through a synthetic ECG example. The [signals overview](/physiokit/reference/) collects shorter examples across modalities. Interactive plots show the saved example waveforms; they are documentation assets, not measurements from a live device.
