## What is physioKIT?

Raw sensor samples rarely answer a question on their own. With ECG, for example, you can clean a waveform, locate R-peaks, derive RR intervals, and calculate heart rate variability. physioKIT exposes those steps as separate Python functions, so you can inspect the intermediate signals and use the measurements you need. The guides below cover pulse, respiration, and motion workflows too.

New to the library? The [quickstart](/physiokit/tutorial/quickstart/) runs that ECG workflow with synthetic data, so no external dataset is needed. Then replace the generated samples with your own recording and set the correct sampling rate. The signal guides show code examples and saved visualizations; the [Python API](/physiokit/api/) documents parameters and return values.

## Installation

In a Python 3.12 project, add physioKIT:

```bash
uv init --python 3.12 my-physio-project
cd my-physio-project
uv add physiokit
```

The [quickstart](/physiokit/tutorial/quickstart/) runs a synthetic ECG example. For an existing recording, follow [Use your own data](/physiokit/tutorial/your-data/). The interactive plots show saved example waveforms, not live measurements.
